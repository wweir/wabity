# General Settings Remediation 2026-03-30

## Scope

修复 `通用` 设置分组在 `2026-03-30` 审计中暴露的几个明确问题：

- 快捷键录制按钮缺少完整可访问命名
- 通知 / 外观 / OCR 被共享双列模板打散
- 通用页顶部重复导航过多
- OCR 区标题动作与字段布局在当前宽度下已经开始挤压换行
- 通用页局部文案中英策略不统一

## Decisions

1. 只修 `general` 分组和它依赖的共享 settings 壳层，不顺手改其它分组。
2. 通用页移除页内 quick jump，保留左侧分组导航和主区标题。
3. 通用页不再复用配置卡通用双列模板；通知、外观、OCR 改成线性单列。
4. 快捷键录制按钮继续保留可见值和动作文案，但额外把字段名绑定进无障碍名称。
5. OCR 的显式保存动作下沉到字段列表后方独立 action row，避免继续挤占卡头横向空间。
