# Icon 更新记录

日期：2026-03-28
阶段：品牌图标替换
范围：`public/`、`src-tauri/icons/`、桌面打包图标入口、网页 favicon

## 背景

仓库原有前端 favicon 仍指向默认 `vite.svg`，桌面端图标资源也沿用脚手架占位资产。它们和当前产品定位不一致：

- 产品气质已经明确收敛为冷静、专业、平和
- 主价值不是“炫目的 AI 外壳”，而是快速唤起、聚焦当前 workspace、执行动作
- launcher 是高频入口，不适合继续挂一个泛用模板图标

## 设计意图

本轮图标的目标不是把 `RAG / ACP / MCP / OCR` 逐项编码进一个小图标，而是收敛到一个更稳定的一级语义：`AI 工作入口 / 调度枢纽`。

- 主体保留 `W`，确保和 `Wabity` 建立直接识别
- 草绿色强调块收敛成一个单一 launcher 条，左右居中并落在偏上的黄金分割位置，同时明确压在主体前景层，优先表达“唤起入口”而不是拆成两个分散高亮块
- `W` 的中轴仍然保留输入主干语义，但不再额外叠一块独立调度核；图标重心回到“launcher 唤起条 + 主体分流结构”
- 色调保持鲜活但不过火的嫩草绿，让整体更有生气，同时继续保持“可接近、低压迫感的 AI 工作入口”而不是冷硬基础设施面板
- 底板仍然保持深色圆角方形和轻微边界，对齐当前 UI 的克制、稳定、低压迫感
- 整体只表达一个母题：`进入一个 AI 调度入口`；具体子系统语义留给产品结构和界面，不强塞进 app icon

## 资产边界

- `public/wabity.svg`：共享品牌源图，也是网页 favicon 源
- `src-tauri/icons/*`：从源图派生出来的桌面平台图标产物

## 生成方式

源图维护完成后，使用 Tauri CLI 生成平台图标：

```bash
npm exec tauri icon -- public/wabity.svg -o src-tauri/icons
```

该命令会统一生成 Tauri 打包所需的 `png`、`icns`、`ico` 等派生资源，避免手工逐个导出导致尺寸或边距漂移。
